# Checkpoint — Plan First, Execute Second
Before writing any code or making file changes:

1. Read `QWEN.md`, `AGENTS.md`, `STATE.md`, and `README.md`
2. Output a numbered execution plan with every action you intend to take
3. Show estimated files to be created/modified
4. STOP and wait for explicit user approval ("go", "yes", or "approved")
5. Only after approval: execute the plan step by step
6. After each step, confirm completion before moving to the next

Never skip the approval step. Never start executing without confirmation.
