## Acceptance Criteria

1. The dataset builder writes JSON files that `BacktestDataLoader.load_all()` can read without adapter changes.
2. Each emitted snapshot includes `token_id`, `condition_id`, `timestamp_utc`, `best_bid`, `best_ask`, `midpoint`, `spread`, `market_end_date`, and outcome fields needed by WI-44.
3. Resolved outcomes are stored separately from point-in-time observable context and cannot be injected into prompts before simulated market close.
4. All price, spread, PnL, and sizing fields are parsed through `Decimal`; raw `float` inputs are rejected at schema boundary.
5. Crossed books, missing token IDs, invalid timestamps, non-positive prices, unresolved markets, and malformed rows are skipped or rejected with typed reasons and `structlog` audit events.
6. HTTP reads use `httpx.AsyncClient` with explicit timeout and bounded retry behavior.
7. The CLI supports `--start-date`, `--end-date`, and `--output-dir`, exits non-zero after exhausted source failures, and writes a manifest on success.
8. Tests cover valid dataset generation, malformed source rows, Decimal rejection of floats, lookahead separation, manifest counts, and integration with `BacktestDataLoader`.
9. No runtime DB writes, live signing, broadcasting, or order-routing calls are introduced by this WI.
10. Full targeted WI tests pass.
11. Full regression remains compatible with the documented 678-test baseline and coverage does not fall below 80%.

## Anti-Patterns

- Do not use raw `float` for money, prices, EV, PnL, spread, or sizing values.
- Do not leak resolved outcomes into prompt/evaluation context before the simulated resolution timestamp.
- Do not invent missing market metadata, balances, fees, positions, prices, or outcomes.
- Do not add direct DB sessions or raw SQL in agent code.
- Do not use `Base.metadata.create_all()` in runtime or dataset paths.
- Do not call live execution, signing, broadcasting, or state-mutating order routes from the dataset builder.
- Do not silently swallow source-data errors.
- Do not commit large generated historical datasets unless explicitly approved.
- Do not log API keys, wallet data, secrets, prompt text, private keys, or full decision reasoning.
- Do not bypass `BacktestDataLoader` compatibility by inventing a parallel replay format.
